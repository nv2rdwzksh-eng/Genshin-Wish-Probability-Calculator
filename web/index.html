    About the calculator—

    We track every possible pity, guarantee, and counter state using exact dynamic programming. Combined mode uses completion-time distributions to plan characters first, then weapons. Community soft pity and the community Capturing Radiance counter are assumed, not official per-wish formulas. Results depend on those assumptions.

    Terms and policies

    This independent fan-made tool is for learning and planning. It is not affiliated with HoYoverse and does not guarantee in-game results. No account, purchase, or wish-history upload is required. Form inputs are sent only to the calculator backend. Settings and up to five calculations stay in your browser; this app does not save calculation history on the server or use analytics. Local server request logs may record request metadata. You can clear history at any time. Exported files are under your control.
